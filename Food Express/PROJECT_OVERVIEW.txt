🚀 QUICK START
════════════════════════════════════════════════════════════════════════════════

1️⃣  AUTOMATED SETUP
    $ bash setup.sh

2️⃣  MANUAL SETUP - Backend
    $ cd backend
    $ npm install
    $ cp .env.example .env
    $ npx prisma migrate dev --name init
    $ npm run seed
    $ npm run dev

3️⃣  MANUAL SETUP - Frontend
    $ cd frontend
    $ npm install
    $ npm run dev

4️⃣  DOCKER SETUP
    $ docker-compose up

5️⃣  ACCESS
    Frontend:    http://localhost:3000
    Backend:     http://localhost:3001
    Admin:       http://localhost:3000/admin
